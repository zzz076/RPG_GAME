# 天樞宗 — 人物關係事件對應文件 (Character Bible)

> **用途**：每次編寫或修改劇情時，必須查閱本文件，確保角色稱謂、關係、個性、事件邏輯前後一致。
> 每個角色的行為都必須能回溯到其**核心驅動力**。

---

## 一、主角

| 項目 | 說明 |
|------|------|
| **姓名** | 由玩家自行輸入（遊戲開始時） |
| **身份** | 天樞宗外門新弟子（村裡被選中的孩子） |
| **背景** | 出身清貧農家，母親只說了「活著回來」。無師承、無靠山。 |
| **性格基調** | 由玩家選擇塑造。不再強制限制為單一的「沉穩冷靜」。 |
| **稱謂規則** | NPC 稱其為「你」或「師弟」（前輩視角）或「新弟子」（長老視角） |

### 主角的多重核心驅動力 (Player Roleplay Archetypes)
玩家可以透過選項決定主角是個怎樣的人。每次設計選項時，應儘量涵蓋以下幾種不同動機的做法（即使殊途同歸），讓玩家有扮演不同人格的空間：

1. **武痴/純粹慕強 (Power-Driven)**
   > **動機**：「我要變強，其他不重要。」
   > **行為**：眼中只有修煉資源和高深武學。選功法直接選最強的，對人際關係冷感或只看實力，遇事崇尚以力破局。
2. **重情義/渴望連結 (Connection-Driven)**
   > **動機**：「在這冷漠的宗門裡，我需要夥伴（或情感寄託）。」
   > **行為**：容易被別人的善意打動（耳根子較軟）。把朋友/同袍看得比利益重。願意為了朋友赴湯蹈火，或是為了建立羈絆而承擔風險。
3. **利己/世故/雞掰人 (Pragmatic/Cynical)**
   > **動機**：「人不為己天誅地滅，這裡全都是算計，大不了互相利用。」
   > **行為**：極度現實，不見兔子不撒鷹。選項可能帶有嘲諷、試探、嘴臭或是極度的戒備。遇到問題優先考慮「這對我有什麼好處？」或是「這是不是陷阱？」。
4. **守規矩/正道 (Lawful/Righteous)**
   > **動機**：「哪怕世道險惡，有些底線和規矩就是不能破。」
   > **行為**：傾向按部就班，相信門規。看不慣私下的小動作或灰色交易。

### 主角的劇情推動原則
- ✅ 允許玩家因為「單純想交朋友」、「想看笑話」或「看他不爽」而作出決定。
- ✅ 不同的選項可以導向同樣的劇情節點，但給予不同的屬性獎勵或 NPC 好感度反饋。
- ✅ 主角因好奇心、觀察力而**自發發現**線索和事件
- ✅ 主角因自身處境/需求而**主動參與**
- ✅ 主角因偶然（路過、撞見）而自然捲入事件
- ✅ 主角作為旁觀者目睹 NPC 之間的事件（不需要是主角）
- ❌ 避免選項只有「聰明的」和「笨的」，應該是「不同價值觀的聰明」。
- ❌ 避免 NPC 毫無理由地信任/重視一個新弟子
- ⚠️ 若 NPC 需要拉主角進入事件，必須有合理動機

## 二、核心 NPC（含核心驅動力）

### 趙元啟

| 項目 | 說明 |
|------|------|
| **身份** | 外門新弟子（與主角**同期入門**），主角的室友 |
| **年齡** | 與主角相仿 |
| **入門時間** | 比主角早到三天（但同屬同一批新弟子） |
| **與主角關係** | 室友 → 朋友（根據玩家選擇深化） |
| **稱謂規則** | ⚠️ **不可稱為「師兄」**。主角稱他「趙元啟」或「元啟」；他稱主角為「室友」「你」或直呼其名 |
| **性格** | 外表隨和嬉皮笑臉，實則心思縝密、城府深。善於偽裝，但對朋友有底線（「我不害朋友」）。 |
| **背景疑點** | 自稱只早來三天，但對宗門的了解遠超三天所能觀察到的範圍。提起周長老時眼神微閃（暗示個人淵源，留待後續章節揭開）。 |
| **口癖/習慣** | 削蘋果（刀功精準）、隨口套話、故意說半句留半句引人思考 |
| **戰鬥/能力特徵** | **【藏拙的暗殺者】** 表面上武藝平平，常在擂台上裝作體力不支而「險勝」或「惜敗」。實則極其擅長短刃近戰與隱匿氣息，能在瞬間爆發出致命一擊。<br>👉 **智取/破綻**：只要限制他的活動空間或逼他在大庭廣眾下使用全力，他就會因為不想暴露實力而選擇主動退讓。 |

#### 🎯 核心驅動力：**求存——在危險的宗門中活下去**

趙元啟來到天樞宗不只是為了修煉。他直覺感知到這裡水很深（可能因為背景中已有某些預知），因此他的一切行為都圍繞著一個核心策略：**在三股勢力的夾縫中求存**。

他的行為邏輯鏈：
1. **收集情報**（比別人更快掌握環境）→ 這就是為什麼他早到三天就密集觀察
2. **尋找盟友**（一個人在三方角力中太危險）→ 這就是他「投資」主角的真正原因——他需要一個能互通消息、互相照應的人
3. **不被收編**（站隊 = 失去自由 = 成為棋子）→ 這就是他「站自己這邊」的原因
4. **留後路**（永遠不把所有信息交出去）→ 這就是他總是說半句留半句的原因

**他對主角的態度不是善意，而是策略性的篩選**：
- 他觀察主角 → 判斷主角是否具備作為盟友的素質（警覺、不衝動、有底線）
- 他分享情報 → 不是免費的善意，而是測試主角的反應+建立互惠關係
- 他提醒主角別站隊 → 因為那也是他自己的策略，他需要盟友和他走同一條路

**⚠️ 常見錯誤**：
- 勿讓趙元啟以「師兄」身份指導主角（他只是早到三天的同期室友）
- 勿讓趙元啟無緣由地帶主角到處走（他只會隨口提起信息，讓主角自己決定）
- 他的信息來源不要解釋得太清楚，保持神秘感
- 他的所有行為都要能回溯到「求存+找盟友」這個核心動機

### 沈峻（大師兄）

| 項目 | 說明 |
|------|------|
| **身份** | 天樞宗大師兄，不明確歸屬任何長老 |
| **年齡** | 28 歲 |
| **與主角關係** | 前輩 → 導師（根據劇情發展） |
| **稱謂規則** | 主角稱「沈師兄」「大師兄」；他稱主角「師弟」或直呼姓名 |
| **性格** | 城府深、武藝高強、外冷內熱。表面冷淡超然，但內心對天樞宗有很強的責任感。 |
| **關鍵秘密** | 修煉天樞心經到第七層，已面臨反噬危機。持有宗主密令的第四份。 |
| **反轉魅力/多面向** | **「貓奴大師兄」**。雖然平時冷得像塊冰，甚至跟蹤觀察弟子時極具壓迫感，但他會在無人的藏經閣屋頂餵野貓，而且如果貓跑了會露出非常明顯的失落表情。這反映了他內心深處其實極度渴望不用算計的「純粹陪伴」。 |
| **戰鬥/能力特徵** | **【絕對壓制的劍道宗師】** 常規狀態下戰鬥力為 100，劍法如霜雪般冷酷精準，沒有多餘動作。<br>👉 **智取/破綻**：因為天樞心經反噬的影響，如果戰鬥拖延超過一炷香時間，或者在極寒天氣下，他的經脈會劇痛，導致動作僵硬，戰鬥力會急遽下降至 60。此外，他對平民或毫無內力的動物（貓狗）有極強的保護慾，絕對不會牽連無辜。 |

#### 🎯 核心驅動力：**找到繼承者——在自己死前把使命傳下去**

沈峻28歲，天樞心經第七層，他知道自己活不過50歲。他的時間不多了。

他的行為邏輯鏈：
1. **觀察每一批新弟子** → 這是他的日常職責，也是他篩選繼承者的手段。所以他出現在 c01-investigate 跟蹤主角是合理的——他對所有表現異常的新弟子都會這樣做。
2. **測試品性而非能力** → 他要求主角「不違本心」而不是「為我效力」——因為他要找的不是棋子而是能獨立判斷的繼承者
3. **不干預長老鬥爭** → 他知道三方平衡遲早崩潰，他要做的是確保有人能在崩潰後重建
4. **持有第四份密令但不使用** → 他在等待合適的人和時機

**他不是主動拉主角進事件，而是在做他本來就在做的事（觀察+篩選），主角恰好進入了他的視線。**

### 林若瑤（二師姐）

| 項目 | 說明 |
|------|------|
| **身份** | 藏經閣常客，與陸長老關係密切 |
| **與主角關係** | 前輩 → 合作者（根據劇情發展） |
| **稱謂規則** | 主角稱「林師姐」「師姐」；她稱主角「你」或直呼姓名 |
| **性格** | 直接、銳利、洞察力極強。不廢話，說話一針見血。 |
| **背景** | 師父（前藏經閣副主事）死於天樞心經反噬，年僅42。她因此執著於找到破解之法。 |
| **戰鬥/能力特徵** | **【毒醫雙絕的學者】** 武功平平（戰力約 40），但精通藥理與毒術。隨身攜帶的銀針能封人穴道或淬毒，正面交鋒極弱，但準備充分的話能越級反殺長老級別人物。<br>👉 **智取/破綻**：不擅長應對近身突襲。且只要涉及到「可能找到破解反噬線索」的情況，她平時極度冷靜的頭腦就會因為過度執著而變得容易上當。 |

#### 🎯 核心驅動力：**為亡師復仇——找到天樞心經反噬的破解之法**

她的一切行為都指向這個目的。她不在乎宗門政治，只在乎真相。

她的行為邏輯鏈：
1. **長期潛伏在藏經閣** → 她需要接觸歷代宗主手記來找線索
2. **與陸長老保持關係** → 陸長老允許她查閱機密資料，這是她的情報來源
3. **等價交換原則** → 她的時間和資源很寶貴（都用在研究上），所以幫人必須有回報
4. **需要幫手但不輕易信任** → 她需要人幫她抄錄機密文獻（不能帶出去），所以會觀察有潛力的新人
5. **匿名提示** → 她不想引起注意（讓人知道她在查什麼），所以用紙條而非直接出面

**注意**：她揭露秘密的速度應與主角的「投入」成正比。
- ❌ 一瓶藥 = 宗門最大秘密（不合理）
- ✅ 一瓶藥 = 一個人情（之後要幫她抄錄文獻），在抄錄過程中主角自己看到了秘密——秘密的揭露應是自然發生的，不是林若瑤主動告訴的

### 宋長老（執法堂）

| 項目 | 說明 |
|------|------|
| **身份** | 天樞宗三長老之一，掌管執法堂 |
| **稱謂規則** | 主角稱「宋長老」 |
| **性格** | 鐵面無私是真，但出手時機都恰到好處——「公正」有時候是一種武器。 |
| **勢力特徵** | 管規矩。手伸得比職權範圍更遠（連不歸他管的管事都怕他）。 |
| **反轉魅力/多面向** | **「極度的強迫症與潔癖」**。他殺人不眨眼，但在審判完犯人後，會仔細地用手帕擦拭劍柄三遍，而且茶杯一定要擺在桌子正中央。他的私室裡種著很多非常嬌貴的花，因為他喜歡「能被精準控制生長的東西」。 |
| **戰鬥/能力特徵** | **【嚴絲合縫的鐵壁劍陣】** 戰鬥以防守反擊為主，一絲不苟，猶如法律條文般無懈可擊。<br>👉 **智取/破綻**：極度討厭混亂與髒汙。如果在戰鬥中向他潑灑泥水、穢物，或者使用極其無賴、不成體統的地痞流氓打法，他的強迫症會發作，節奏會大亂。 |

#### 🎯 核心驅動力：**維護秩序——但他定義的秩序**

宋長老真心相信規矩的力量。但他也明白「誰掌握規矩的解釋權，誰就掌握權力」。

他的行為邏輯鏈：
1. **選擇性執法** → 他的公正是真的，但何時執法是策略性的。在周長老談妥商路後立刻處罰其弟子 = 用公正的名義打壓對手
2. **招募「乾淨」的調查者** → 他需要不屬於任何派系的人做事，這是工具性的需求而非善意
3. **喜歡坦誠的人** → 因為坦誠的人好控制、好預測
4. **為什麼關注比武中的新弟子** → 他在觀察新一代中誰適合成為「規矩的執行者」（即他的工具）

### 陸長老（藏經閣）

| 項目 | 說明 |
|------|------|
| **身份** | 天樞宗三長老之一，掌管藏經閣 |
| **稱謂規則** | 主角稱「陸長老」。他自稱「老夫」。 |
| **性格** | 表面和藹慈祥，實則城府最深。不主動出手，讓情報自然運作。 |
| **反轉魅力/多面向** | **「嗜甜如命的老頑童」**。雖然掌握了所有人致命的秘密，隨時能置人於死地，但他辦公的桌子抽屜裡塞滿了各種凡俗甜食（糖葫蘆、桂花糕）。如果主角送他珍貴的功法孤本他可能只會微微點頭，但如果主角從山下帶了排隊才買得到的限量糕點，他可能會不小心多透漏兩句情報。他的殘酷和他的孩子氣同時存在。 |
| **戰鬥/能力特徵** | **【不戰而屈人的精神控制者】** 本身年事已高，不善近戰纏鬥，但他修習的「惑心音」能在說話間影響對手心智，未戰先讓敵人恐懼退縮。<br>👉 **智取/破綻**：只要封閉聽覺，或是心智如同野獸/極端武痴般純粹（完全不聽他講話直接砍），他的威脅就會大幅下降。 |

#### 🎯 核心驅動力：**情報壟斷——讓所有人都依賴自己，從而確保自身不可取代**

他不追求宗主之位，他追求的是「不管誰當宗主都少不了我」。

他的行為邏輯鏈：
1. **記住每個弟子的選擇** → 情報收集是他的本能，每個來借書的人都在給他提供數據
2. **因人推薦不同功法** → 不是為了弟子好，是為了「佈局」——讓特定的人學特定的東西，以便將來能為他所用
3. **不阻止弟子犯錯** → 犯錯的人會需要幫助，需要幫助的人就會成為他的「客戶」（參見讓主角自行選擇進階劍術的場景）
4. **允許林若瑤查閱機密** → 他知道林若瑤在查什麼，但他默許因為林若瑤的研究成果最終也是情報
5. **「品茶」邀約** → 他的招募方式——在輕鬆的氛圍中評估和收編

**關鍵特質**：他不是棋手，他是「賣武器的商人」。所有人的爭鬥都會增加他的價值。

### 周長老（外務堂）

| 項目 | 說明 |
|------|------|
| **身份** | 天樞宗三長老之一，掌管外務堂 |
| **稱謂規則** | 主角稱「周長老」 |
| **性格** | 表面豪爽、出手大方，實則精於利益算計。 |
| **反轉魅力/多面向** | **「摳門的土豪」**。他對外砸錢買情報、拉攏人心時幾千兩眼都不眨，但他私底下自己的衣服破了都是自己縫（而且縫得很醜）。他最看不起浪費糧食的人。他的豪爽是一種投資手段，他的摳門才是他的本性——因為他小時候真的餓過肚子，這是他積累資源的深層心理創傷。 |
| **戰鬥/能力特徵** | **【力大磚飛的重兵器】** 武器是一把極重的精鋼開山斧，招式大開大合，威力驚人，加上他身上的護甲全是用宗門最頂級的材料打造，完全是個「氪金戰士」。<br>👉 **智取/破綻**：醉酒後力量會翻倍（戰力爆氣），但方向感全無，很容易打中自己人。此外，他對「金錢和資源」有著本能的吝嗇——如果在戰鬥中毀損了極其貴重的東西，他會因為心痛而露出致命破綻。 |

#### 🎯 核心驅動力：**積累資源——為天樞宗（和自己）的未來買保險**

周長老是三人中最「務實」的。他知道宗主可能回不來了，宗門需要資源才能存續。他的灰色生意不全是私心——部分是為了讓天樞宗在亂世中有足夠的物資底氣。但他也確實從中中飽私囊。

他的行為邏輯鏈：
1. **門下弟子最多** → 他用資源換忠誠，需要大量人手經營商業網絡
2. **灰色交易** → 靈礦低價出售給南疆商會，可能是在建立宗門之外的關係網（後手）
3. **宗主閉關當晚哭了** → 暗示他與宗主有私人感情（可能是師兄弟或多年摯友），他的急迫不全是野心，也有感情成分

## 七、劇情推動方式指南

### ✅ 正確的推動方式（主角主動/自然捲入）

1. **主角觀察力觸發**
   > 「你注意到管事跳過了幾處地方」「你看到韓策變招前左腳內扣」
   
2. **主角因自身需求行動**
   > 主角想變強 → 自己去藏經閣借書；主角想了解環境 → 自己四處走動

3. **主角意外目睹**
   > 路過時撞見長老私下對話、在修煉時聽到院外腳步聲

4. **主角行為引起 NPC 注意**（被動觸發但有因果鏈）
   > 主角四處打探 → 沈峻在例行巡視中注意到 → 沈峻來詢問

### ❌ 應避免的推動方式

1. **NPC 無理由帶主角進入事件**
   > ❌「趙元啟帶你去演武場」→ ✅「趙元啟隨口提到演武場有事，你自己決定要不要去」

2. **NPC 無理由信任/重視新弟子**
   > ❌ 長老主動邀約一個入門幾天的新人 → ✅ 主角的某個行為（如比武表現、觀察力）引起長老注意

3. **NPC 主動傾倒情報**
   > ❌ 趙元啟主動告訴主角所有長老的情報 → ✅ 主角問了什麼，趙元啟才回答什麼（主角驅動對話）

## 八、主角不一定是事件中心

玩家不需要是每個事件的主角。以下是設計原則：

### ✅ 好的設計：主角是旁觀者/邊緣參與者
- 主角目睹宋長老處罰弟子 → 他只是眾多觀眾之一，不是事件焦點
- 比武時主角觀察韓策 vs 其他人的對戰 → 主角作為觀察者收集信息
- 長老之間的對話被主角偶然聽到 → 主角不是對話的對象

### ✅ 好的設計：NPC之間的事件自然發生
- 宋長老處罰周長老弟子 → 這是宋周之間的博弈，跟主角無關，主角只是撞見了
- 韓策對周長老的交易感到不安 → 這是韓策自己的內心矛盾，不是為了拉主角進來
- 林若瑤在藏經閣研究 → 她本來就在做自己的事，主角去了碰巧遇到

### ❌ 壞的設計：所有事件都圍繞主角展開
- ❌ 三個長老同時搶一個輸了比武的新弟子 → 不合理
- ❌ 大師兄對一個入門一天的弟子全程跟蹤 → 需要更好的理由
- ❌ 林若瑤對一個完全不認識的人警告 → 缺乏因果鏈
