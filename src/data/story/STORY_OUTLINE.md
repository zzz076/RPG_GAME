# 故事骨幹 — 第三章：風暴

## 時間：第二章結束翌日清晨

## 開場
```
所有第二章結局 → c03-001（禁地第二次爆發，威力十倍）
  ↓
三條開場路線匯聚 → c03-crisis（正殿，三長老撕破臉）
```

## 三方決裂 → 四路分支
```
c03-crisis
  ├→ c03-side-song（宋長老：巡邏封鎖 → 發現魏無期 → 第三次震動 → 宋長老動搖）
  ├→ c03-side-lu（陸長老：交易 → 藏經閣暗道 → 林若瑤同行）
  ├→ c03-side-zhou（周長老：衝山門 → 落石封路 → 續命蘭真相 → 嚴墨出現）
  └→ c03-side-none（獨立：找沈峻 → 第四份密令 → 選同行者）
       ↓
  四路匯聚 → c03-before-gate（禁地入口）
```

## 歸墟殿
```
c03-before-gate → c03-forbidden-gate [CHECK: 內力≥8]
  ├→ pass: c03-gate-open
  └→ fail: c03-gate-struggle（魏無期合力，生命-15）
       ↓
c03-enter（發現宗主被困、穹頂完整功法）
  ↓
c03-heart-sutra → c03-guardian（守護者意圖考驗）→ c03-final-choice
```

## 最終抉擇
```
c03-final-choice
  ├→ c03-master-check [CHECK: 內力≥10] → 破繭(pass) / 碎道(fail)
  ├→ c03-ending-heir（傳燈：交沈峻）
  ├→ c03-ending-reform（破舊立新：公開功法）
  └→ c03-other-choice
       ├→ c03-ending-sacrifice（燃燈：犧牲救宗主）
       ├→ c03-ending-seal（再封：重新封印）
       ├→ c03-ending-exile（南渡：帶功法去南疆）
       └→ c03-ending-shadow（暗主：獨佔功法）
```

## 8個結局
| 結局 ID | 結局名 | 觸發條件 |
|---------|--------|---------|

| c03-ending-exile | 南渡 | 帶功法離開天樞宗，去南疆 |
| c03-ending-shadow | 暗主 | 獨佔功法，欺騙所有人 |
