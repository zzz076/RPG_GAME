# 屬性系統說明

## 基礎屬性
| 屬性 | 初始值 | 用途 | Check 門檻範圍 |
|------|--------|------|---------------|
| 武力 | 5 | 戰鬥力、近戰 check | 6~7 |
| 內力 | 3 | 心法修煉、內功 check | 未使用 check |
| 敏捷 | 5 | 身法、躲避 check | 6 |
| 智謀 | 5 | 謀略、觀察 check | 7~8 |
| 名聲 | 0 | NPC 態度、社交影響 | 未使用 check |
| 生命 | 100 | 歸零則死亡 | N/A |

## 性格屬性（影響可用選項）
| 屬性 | 初始值 | 代表 | requirement 門檻 |
|------|--------|------|-----------------|
| 向武 | 0 | 武痴/慕強 | ≥1 |
| 重情 | 0 | 重情義/渴望連結 | ≥1 |
| 世故 | 0 | 利己/務實/世故 | ≥1 |
| 桀驁 | 0 | 狂放/不羈/挑釁 | ≥1~2 |
| 守正 | 0 | 守規矩/正道 | 未使用 |

## 屬性增長預期（第一章各路線）
- **武痴路線**：武力 +4~8, 內力 +2~4
- **社交路線**：名聲 +4~8, 智謀 +2~4
- **謀略路線**：智謀 +6~12（膨脹最快，注意控制）
- **守正路線**：名聲 +2~4, 內力 +2~4

## 設計原則
- 智謀增長過快，設計新選項時避免無差別給智謀
- 武力/敏捷增長較慢，相應 check 門檻應低於智謀
- 性格屬性 requirement 用於解鎖特殊選項（≥1 即可觸發）
- 生命扣除不超過 -15（除非是嚴重後果）
