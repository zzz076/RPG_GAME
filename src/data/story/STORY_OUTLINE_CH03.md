# 故事骨幹 — 第三章：風暴

## 時間設定
第二章結束翌日。入門約三個月零一週。

## 核心事件
禁地第二次劇烈異動，外牆震塌一段，陣法出現裂縫。三長老的脆弱平衡徹底崩潰。主角被迫在混亂中選擇立場，最終進入歸墟殿，發現宗主的真實狀態和天樞心經的完整真相。

## 核心揭露（本章新增）
- 宗主仍活著但被反噬困住，意識清醒卻無法脫出
- 歸墟殿內壁刻有初代宗主留下的正魔合一完整功法
- 沈峻的第四份密令內容：歸墟殿的開啟口訣
- 三長老各自的終極目的在壓力下暴露
- 歸墟殿內有初代宗主留下的「守護者」殘念（歸墟組織的最後遺產）

---

## 開場（共通入口）

```
c03-001（清晨，禁地方向傳來巨響，地面劇烈震動，窗戶碎裂）
  ├→ c03-check-damage（衝出門往禁地方向跑）
  ├→ c03-find-allies（先找趙元啟和魏無期）
  └→ c03-stay-alert（觀察其他人的反應再行動）
```

**c03-check-damage**：
- 揭露：禁地外牆塌了一段，陣法出現肉眼可見的裂縫，金色光芒從裂縫中滲出
- 遇到沈峻在裂縫前站著，神色凝重
- 選擇：問沈峻 / 試著靠近裂縫 / 回去匯報
- → 匯入 c03-crisis

**c03-find-allies**：
- 趙元啟已經起來了，正在收拾東西（像是隨時準備跑）
- 魏無期不在房間，床上留了一把匕首（他去禁地方向了）
- 選擇：跟趙元啟一起去正殿 / 去找魏無期
- → 匯入 c03-crisis

**c03-stay-alert**：
- 從窗口觀察：弟子們驚慌跑動，宋長老帶執法堂弟子封鎖主道
- 陸長老反方向走——回藏經閣
- 周長老召集商隊弟子往山門集結
- 揭露：三方第一反應就暴露了各自的優先級
- → 匯入 c03-crisis

## 前段：危機爆發 → 選邊站

**c03-crisis**（正殿前廣場，三長老公開對峙）：
- 宋長老宣佈全宗戒嚴，任何人不得離開宗門，違者視同叛宗
- 周長老當面反對：「宗主需要續命蘭，我必須下山取藥，你攔不住我」
- 陸長老冷笑：「續命蘭治標不治本。解藥在禁地裡，不在山下」
- 三人話鋒越來越尖。宋長老拔劍。周長老的弟子圍上來。陸長老轉身就走
- **揭露**：三長老各自知道的不一樣——宋知道規矩但不知禁地真相；陸知道歸墟殿但缺鑰匙（主角）；周知道續命蘭但不知根本解法
- 選擇四路：

```
c03-crisis
  ├→ c03-side-song（站到宋長老身邊，幫助維持秩序）
  ├→ c03-side-lu（追上陸長老，跟他合作）
  ├→ c03-side-zhou（跟周長老一起突圍出山）
  └→ c03-side-none（趁三方對峙，悄悄離開去找沈峻）
```

## 四條路線詳細展開

### A. 宋長老路線（c03-side-song）

**核心邏輯**：宋長老要秩序，但秩序擋不住禁地崩塌。他最終必須承認自己錯了。

```
c03-side-song（宋長老派你和韓策巡邏封鎖通往禁地的路）
  ↓
c03-song-patrol（巡邏途中遇到魏無期正在試圖接近裂縫）
  ├→ c03-stop-wei（攔住魏無期）→ 魏無期被迫展示正魔力量自證
  └→ c03-let-wei（放他過去）→ 韓策目睹，陷入矛盾
  ↓
c03-song-quake（第三次震動，更強，禁地裂縫擴大。金光衝天）
  → 宋長老趕到現場，親眼見到裂縫中的異象
  ↓
c03-song-admit（宋長老第一次露出動搖：「戒嚴沒有用。」）
  ├→ c03-song-suggest（「讓我進去看看」）
  └→ c03-song-wait（等沈峻來）→ 沈峻趕到
  ↓
→ 匯入 c03-before-gate
```

**本路線揭露**：
- 宋長老的真正恐懼：不是失去權力，是秩序本身的崩塌
- 韓策的內心衝突：忠於周長老但認同宋長老的做法
- 魏無期已經獨自嘗試過接近歸墟殿（帶傷的原因）

**同行者到達禁地**：宋長老（遠距離監督）+ 韓策 + 魏無期

---

### B. 陸長老路線（c03-side-lu）

**核心邏輯**：陸長老是最接近真相的人，但他需要主角當鑰匙。交易的本質是互相利用。

```
c03-side-lu（追上陸長老回藏經閣，他鎖上門後轉身看你）
  → 陸長老攤牌：「你來得正好。密信的完整內容我一直沒說——歸墟殿的開啟需要兩個條件：正魔合一之人的血，和初代宗主留下的口訣。口訣在宗主的密令裡。」
  ↓
c03-lu-deal（陸長老提出交易：他幫你進歸墟殿，你把裡面的功法抄一份給他）
  ├→ c03-lu-accept（答應交易）
  ├→ c03-lu-counter（反提條件：「你先告訴我密信的全部內容」）
  └→ c03-lu-refuse（拒絕：「我不是你的工具」）→ 陸長老不阻攔但也不幫忙
  ↓
c03-lu-lin（林若瑤出現：「陸長老，我也想去。我師父的死因可能就在那裡。」）
  → 陸長老同意讓林若瑤同行（他需要她的醫術知識以防萬一）
  ↓
c03-lu-passage（陸長老帶路，走藏經閣地下暗道直通禁地後山）
  → 揭露：這條暗道是初代宗主修建的，陸長老花了十年才找到
  ↓
→ 匯入 c03-before-gate
```

**本路線揭露**：
- 密信完整內容：開啟歸墟殿的兩個條件（血 + 口訣）
- 藏經閣地下有暗道通往禁地（初代宗主修建）
- 陸長老十年前就開始準備，他等的不只是情報——是機會
- 林若瑤的師父可能不是死於普通反噬，而是試圖自行開啟歸墟殿失敗

**同行者到達禁地**：林若瑤 + 陸長老（暗中跟隨）

### C. 周長老路線（c03-side-zhou）

**核心邏輯**：周長老的務實主義遇到了天花板——續命蘭治標不治本。他不得不面對真相。

```
c03-side-zhou（跟周長老和韓策帶商隊往山門衝）
  ↓
c03-zhou-blocked（山門外的山路被禁地震動引發的落石封住了）
  → 周長老試圖清路，但禁地方向又一次脈動，山體持續不穩
  ├→ c03-zhou-force（幫周長老強行清路）→ check: 武力 ≥ 7
  └→ c03-zhou-talk（勸周長老放棄下山）
  ↓
c03-zhou-truth（周長老在挫敗中說出真話：「續命蘭我送了五年。宗主的狀況……越來越差。上個月的藥量是第一年的三倍。」）
  → 揭露：周長老一直在偷偷給宗主送藥，但效果遞減。他知道這不是長久之計
  ↓
c03-zhou-return（嚴墨忽然出現在山路盡頭：「周長老，續命蘭已經沒用了。讓那個孩子去歸墟殿——這是唯一的辦法。」）
  → 周長老看向你。第一次用正眼看你
  ├→ c03-zhou-agree（「我去。」）→ 周長老讓韓策護送你回禁地
  └→ c03-zhou-condition（「你跟我一起去。」要求周長老同行）
  ↓
→ 匯入 c03-before-gate
```

**本路線揭露**：
- 周長老五年來一直在給宗主秘密送續命蘭（他的灰色生意有一部分是為宗主）
- 藥效遞減，宗主狀況在惡化
- 嚴墨一直在附近沒走遠，他也在等歸墟殿開啟的時機
- 周長老並非純粹為私利——他用自己的方式在救宗主

**同行者到達禁地**：韓策 + 嚴墨（周長老路線獨有）

### D. 獨立路線（c03-side-none）

**核心邏輯**：不依附任何長老，直接找掌握最關鍵信息的人——沈峻。

```
c03-side-none（趁三方對峙混亂，從側門溜走）
  ↓
c03-find-shen（在後山崖邊找到沈峻，他在餵貓，像什麼都沒發生一樣）
  → 沈峻：「你來了。比我預想的快。」
  ↓
c03-shen-order（沈峻掏出一張泛黃的紙：「第四份密令。宗主閉關前親手交給我的。」）
  → 揭露密令內容：歸墟殿入口在禁地正殿下方第三層石階，開啟口訣是一段梵文
  → 沈峻：「但只有口訣不夠。還需要正魔合一之人的力量共鳴。宗主當年就是因為只有正道之力，強行開啟失敗，才被反噬困住。」
  ↓
c03-shen-team（沈峻問：「你打算帶誰去？」）
  ├→ c03-call-zhao（找趙元啟）→ 趙元啟：「我等你這句話很久了」
  ├→ c03-call-wei（找魏無期）→ 魏無期已經在路上了
  └→ c03-go-duo（只跟沈峻兩人去）
  ↓
→ 匯入 c03-before-gate
```

**本路線揭露**：
- 第四份密令的完整內容（口訣 + 開啟位置）
- 宗主當年就是因為強行開啟歸墟殿才被困住的（五年閉關的真正原因）
- 沈峻一直在等「正魔合一之人」出現——他知道自己的心經修為已到極限，時日無多

**同行者到達禁地**：沈峻 + 趙元啟或魏無期

## 中段：禁地入口（四路匯合）

```
c03-before-gate（禁地正殿前，各路線到達）
  → 不管哪條路線，沈峻都會趕到（如果不在身邊，他獨自趕來）
  → 他交出/唸出口訣
  ↓

  fail → c03-gate-struggle（力量不穩定，魏無期補上另一份力量，勉強開啟。主角受傷 -15生命）
  ↓
c03-descend（走下階梯，同行者跟隨）
  → 階梯盡頭是一座巨大的地下石殿
```

## 後段：歸墟殿內

```
c03-enter（歸墟殿全貌：圓形石殿，穹頂刻滿文字，正中央有一個人形輪廓被金色光芒包裹）
  → 揭露：那個人形輪廓是宗主。他沒死，但被反噬的力量封在原地，像琥珀裡的蟲
  ↓
c03-sect-master（靠近宗主）
  → 宗主的意識微弱傳來：「你……終於來了。」
  → 揭露：宗主五年前嘗試獨自開啟歸墟殿，失敗後被反噬困住。他用殘餘的力量維持封印不崩塌
  → 「穹頂上的文字……就是完整的功法。但修煉它有代價。初代宗主寫過——正魔合一者，得功法全貌，卻需以自身修為為引。」
  ├→ c03-ask-price（「代價是什麼？」）
  └→ c03-read-walls（先去看穹頂的文字）
  ↓
c03-heart-sutra（穹頂文字：正魔合一完整版天樞心經。林若瑤/陸長老/沈峻看了都震驚）
  → 揭露：功法確實完整，能破解反噬。但修煉需要以修煉者當前的全部修為為代價「重鑄經脈」
  → 成功率未知。初代宗主自己沒有修煉過——因為他不是正魔合一體質
  ↓
c03-guardian（石殿深處浮現一團黑霧——初代宗主留下的「守護者」殘念）
  → 守護者考驗來者的意圖（不是戰鬥，是問答）
  → 「你要這功法做什麼？」
  ├→ c03-answer-save（「救宗主。」）→ 守護者：「善。但他已撐了五年，身體未必受得住。」
  ├→ c03-answer-self（「修煉它，讓自己變強。」）→ 守護者：「誠實。但貪婪者往往付出最多。」
  ├→ c03-answer-destroy（「看看它是什麼，再決定要不要銷毀。」）→ 守護者：「謹慎。但真相不會因為你不看就消失。」
  └→ c03-answer-share（「帶出去，讓所有人都能修煉。」）→ 守護者：「天真。但天真有時比智慧更接近正道。」
  ↓
c03-guardian-pass（守護者消散，功法完全開放）
  → 此時外面傳來動靜——其他勢力也在往歸墟殿趕來
  → 時間不多，你必須現在做出選擇
```

## 最終抉擇 → 8個結局

```
c03-final-choice（功法在眼前，宗主在身邊，外面的人在逼近）
  ├→ c03-try-cultivate（嘗試當場修煉完整功法）
  ├→ c03-give-shen（把功法交給沈峻）
  ├→ c03-give-public（抄錄功法，帶出去公開）
  └→ c03-other-choice（第二輪選擇）

c03-other-choice
  ├→ c03-try-save（用現有的力量嘗試救宗主，不修煉完整功法）
  ├→ c03-reseal（重新封印歸墟殿）
  ├→ c03-take-south（帶功法離開，去南疆）
  └→ c03-keep-secret（獨佔功法，不告訴任何人）
```

### 結局詳細

**c03-try-cultivate → c03-ending-master（破繭）**
- 主角修煉完整功法，經脈重鑄成功
- 用新力量解除宗主的封印反噬
- 宗主甦醒，天樞宗危機解除
- 代價：主角失去原有全部修為，從零開始
- 結語：破繭重生者，終將振翅

**c03-give-shen → c03-ending-heir（傳燈）**
- 把功法交給沈峻——他的時日無多，但他有足夠的智慧
- 沈峻決定自己修煉，用最後的生命嘗試救宗主
- 主角離開歸墟殿，承擔起沈峻的責任：守護天樞宗直到沈峻成功或失敗
- 結語：薪火相傳，燈燈相續

**c03-give-public → c03-ending-reform（破舊立新）**
- 抄錄功法帶出歸墟殿，當著三位長老的面公開
- 三長老的權力基礎（壟斷心經知識）瓦解
- 天樞宗劇變：舊秩序崩塌，新規則待建
- 主角成為改革的推動者，但也成為所有保守派的眼中釘
- 結語：舊瓶碎了，新酒還沒釀好

**c03-try-save → c03-ending-sacrifice（燃燈）**
- 不修煉完整功法，而是用自身正魔合一的力量直接灌入宗主體內
- 宗主甦醒，但主角的正魔力量被抽空，經脈受損
- 主角變成一個普通人——不再能修煉
- 趙元啟哭了。魏無期沉默地扶著你走出歸墟殿
- 結語：有人燃盡自己，照亮別人的路

**c03-reseal → c03-ending-seal（再封）**
- 判斷功法太危險，重新封印歸墟殿
- 宗主繼續被困，但封印穩固了
- 三長老被迫重新坐下談判——因為唯一的解法被封了
- 主角背負「放棄拯救宗主」的罵名，但避免了功法外洩的風險
- 結語：有些門，打開容易，關上才是勇氣

**c03-take-south → c03-ending-exile（南渡）**
- 帶著功法離開天樞宗，去南疆找母親的師門
- 嚴墨在山門外等著你（如果走過周長老路線，嚴墨會在場）
- 離開前回頭看了一眼——趙元啟站在山門裡，沒有跟來，但他點了點頭
- 結語：有些真相需要在別處尋找

**c03-keep-secret → c03-ending-shadow（暗主）**
- 獨佔功法。告訴所有人歸墟殿裡什麼都沒有
- 從此你是唯一知道完整天樞心經的人
- 三長老繼續內鬥，但你手握最終底牌
- 代價：背叛了所有信任你的人
- 結語：棋手從不讓棋子知道棋局的全貌

**c03-ending-sacrifice 的變體——如果宋路線 + 回答「救宗主」**：
- 不單獨列結局，但 c03-ending-sacrifice 的文字會根據路線有微調

## 關鍵設計原則
- 所有路線殊途同歸至歸墟殿（但同行者、掌握的信息、與 NPC 的關係不同）
- 歸墟殿內的選擇才是結局分歧點（前面的路線影響氛圍和同行者，不影響結局選項）
- 宗主的真實狀態是情感核心——五年來他一個人在地下撐著封印
- 守護者的問答不是戰鬥，是靈魂拷問：你要這力量做什麼？
- 每個結局都有代價，沒有完美結局
